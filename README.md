# Memory-Plastic Cellular Automata

This repository contains the main Python implementation used for the memory-plastic cellular automata project.

## Scope

The code supports classical and quantum-like local-state cellular automata with configurable interaction geometry, memory, plasticity, update order, and perturbation protocols.

- `src/`: main Python source code
- `LICENSE`: terms of use
